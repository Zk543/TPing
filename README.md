# TPing 局域网投屏

把安卓手机的屏幕和声音，低延迟地投到同一局域网内的 Windows 电脑上。

手机和电脑不需要连同一台路由器的同一个 SSID，只要在**同一个局域网**里能互通就行。整个投屏过程不经过公网。

## 使用步骤

1. **电脑**：安装并运行「局域网投屏接收端」，界面会显示一个二维码和一个 6 位房间号。
   - 首次运行如果防火墙弹窗，**允许**局域网访问。
2. **手机**：安装 APK，打开后选择与电脑处于同一网络的 WLAN。
3. 用手机**扫码**，或手动输入房间号，即可开始投屏。

投屏开始后：

- 电脑上鼠标移到窗口底部会浮出**控制栏**，可以截图、录制、切换音频输出设备。
- 控制栏左侧的 HUD 显示实时链路状态（缓冲区、上屏帧率、丢包、解码耗时等），
  把鼠标悬停在它上面可以看到更详细的诊断数据。

## 声音

投屏默认会把**手机的声音**一起带过来。

发送端可以选择声音往哪儿出：

- **接收端输出**（默认）：声音跟着画面，从电脑的音箱/耳机出来
- **手机扬声器**：声音留在手机
- **蓝牙耳机**：声音走手机上已连接的蓝牙设备

> 注意：Android 系统限制，当手机的音频正连接到蓝牙耳机（尤其是走 A2DP offload）时，
> 第三方应用无法可靠地截获并转发这部分声音。这种情况下建议改成「接收端输出」，
> 也就是让声音直接从电脑那边出来。

## 关于画质与帧率

接收端**设置**里可以调整**视频帧率上限**：

- **跟随显示器**：自动读取这台电脑的刷新率，取一个可稳定呈现的帧率
- **30 / 60 fps**：手动指定

软件内置了自动稳帧机制：如果实测发现某个帧率下画面上屏不稳定，
会自动下调一两档到能稳定呈现的水平，并在 HUD 里注明原因。
手动改过帧率设置之后，这个自动判断会重置，交回给你决定。

## 常见问题

**投屏画面卡顿，但 HUD 显示丢包是 0**

先看 HUD 悬停信息里的 `GPU合成` 一行。如果显示 `disabled_software` 之类的软件实现，
说明显卡走的是软件合成，这是驱动层面的问题（可以尝试更新显卡驱动）。

**连不上 / 手机上搜不到房间**

确认手机和电脑在同一个局域网（不是各自开了热点，也不是隔离访客网络），
并且电脑防火墙允许了这个程序在局域网通信。

**第一次装 Windows 端的 SmartScreen 提示**

因为这个安装包没有做代码签名，Windows 会提示「未知发布者」。
点「更多信息」→「仍要运行」即可。

## 技术栈

- 传输：LiveKit SFU（服务端程序已内置在接收端里，开箱即用，无需另配服务器）
- 接收端：Electron + 原生 WebRTC
- 发送端：Android MediaProjection + WebRTC
